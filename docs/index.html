Что можно делать

Составлять сметы

Добавляйте работы по разделам, указывайте объёмы и сразу видите итог.

Настраивать расценки

Ведите свой справочник, задавайте цены для разных условий монтажа и добавляйте единицы измерения.

Работать офлайн

Сметы хранятся на устройстве. Для переноса данных можно сохранить резервную копию.

Установка и обновления

Откройте актуальный релиз на телефоне, скачайте APK и подтвердите установку. Для проверки новой версии откройте «Настройки» → «Обновления» → «Проверить обновления».
